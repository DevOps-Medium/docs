# DevOps Medium docs

Every published doc on [devopsmedium.com](https://devopsmedium.com), as plain Markdown. Each
folder is a space and files follow the site's URLs: `tutorial/linux/permissions.md` is
https://devopsmedium.com/tutorial/linux/permissions, and a folder's `README.md` is the folder's own page.

This repository is a one-way mirror, written by the site on every publish. Changes made here are
overwritten; to suggest a fix, use the contact page on the site.
